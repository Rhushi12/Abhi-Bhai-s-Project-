# Excel Automation App 📊

A simple, fast, and secure tool to automate Excel data transfer.
Powered by Python and Streamlit.

## 🚀 How to Run (Windows & Mac)

1. **Install Requirements** (First time only)
   Open Terminal/Command Prompt and run:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the App**
   ```bash
   streamlit run app.py
   ```
   *If that doesn't work, try:* `python -m streamlit run app.py`

The app will open automatically in your browser.

## 🌐 How to Put Online (Free & Unlimited)

1. Upload this folder to **GitHub**.
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Connect your GitHub account.
4. Select your repository and `app.py`.
5. Click **Deploy**.

That's it! Your tool is now online and accessible from any device (Mac, Windows, iPad).
